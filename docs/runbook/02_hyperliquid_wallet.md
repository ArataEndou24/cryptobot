# 手順書 02: ウォレットと Hyperliquid の準備

対象: 運用者。まずテストネット（仮想資金）だけを準備する。本番資金は手順書 03 の条件を満たしてから。

## 1. 仕組みの理解（5 分）

- Hyperliquid は分散型取引所。口座の代わりに **ウォレット（イーサリアム形式のアドレス）** を使う。
- 資金は **Arbitrum というネットワーク上の USDC** で入金する。
- ボットには **API ウォレット（エージェントウォレット）** という別の鍵を渡す。
  この鍵は注文はできるが **出金はできない**。サーバーが乗っ取られても資金は盗めない。
- つまり鍵は 2 種類ある。
  1. **メインウォレット**: 資金を持つ。鍵は絶対にサーバーに置かない。
  2. **API ウォレット**: ボット専用。鍵は VPS の `.env` にだけ置く。

## 2. メインウォレットの作成

- ハードウェアウォレット（Ledger 等）が最も安全。なければ MetaMask や Rabby などのブラウザ拡張。
- **シードフレーズ（復元用の 12〜24 単語）は紙に書いてオフラインで保管する。** 写真、クラウド、メモアプリには置かない。
- 作ったアドレス（0x から始まる公開アドレス）は共有して構わない。秘密鍵とシードフレーズは誰にも渡さない。私にも渡さない。

## 3. テストネットへの接続

1. https://app.hyperliquid-testnet.xyz を開き、ウォレットを接続する。
2. テストネット用の仮想 USDC を受け取る（faucet）。
   faucet はメインネットで一定の利用歴があるアドレスだけに配布する場合がある。
   受け取れないときは、その旨を報告してください。別の方法を案内します。
3. API ウォレットを作る: 画面の「API」または「More → API」から新しい API ウォレットを生成し、
   **その秘密鍵を VPS の `.env` の `HL_API_WALLET_PRIVATE_KEY` に貼る**。
   メインウォレットの公開アドレスを `HL_MAIN_ADDRESS` に貼る。
4. `make doctor` を実行し、「Hyperliquid API（testnet）」が OK であることを確認する。

## 4. 本番資金の入金経路（今は実行しない。流れの理解だけ）

1. 国内の暗号資産交換業者で暗号資産を買う。
2. 自分のメインウォレット（Arbitrum ネットワーク）に送金する。送金手数料と対応ネットワークは業者ごとに確認する。
3. Arbitrum 上で USDC に交換する（必要な場合）。
4. Hyperliquid の画面から「Deposit」で USDC を入金する。

注意: 送金先ネットワークを間違えると資金を失う。最初は少額で試す。
`.env` の各項目の意味は `.env.example` のコメントに書いてある。

## 5. 税務の記録

Hyperliquid での損益は雑所得として申告対象になる。ボットは全ての約定を記録し、
確定申告に使える形式で出力する機能を後の段階で用意する。
それまでは Hyperliquid の画面からも履歴を出力できる。
